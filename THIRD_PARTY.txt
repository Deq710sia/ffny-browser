Browser runtime adaptations reference DefJamFFNY-recomp and xboxrecomp.
No game data or generated code is licensed or distributed here.

The browser GPU adapter (runtime/browser_gpu.c) and build-local extracted
NV2A register handlers use LGPL-2.1-or-later components from xboxrecomp/xemu:
nv2a_core.c, nv2a_regs.h and portions of the host state layout.
Copyright (c) 2012 espes; 2015 Jannik Vogel; 2018-2025 Matt Borgerson.
The adapter replaces native platform dependencies with explicit browser MMIO,
and rejects unsupported registers. Original handlers are taken from the pinned
upstream checkout by scripts/build-probe.py; their source and modifications
remain available for rebuilding/relinking. See LICENSES/LGPL-2.1.txt.
Upstream: https://github.com/xemu-project/xemu

Browser APU adaptation: runtime/browser_apu.c and runtime/browser_apu_shim.h,
with build-local apu_core.c register handlers, apu_state.h and apu_vp.c generated
by scripts/generate-apu.py. The pinned xemu/xboxrecomp APU source is LGPL-2.1-or-later:
Copyright (c) 2012 espes; 2018-2019 Jannik Vogel; 2019-2025 Matt Borgerson.
Sources, adaptation scripts and object files remain available for relinking.
See upstream/tools/xboxrecomp/src/apu and LICENSES/LGPL-2.1.txt.

Browser USB adaptation now also reuses the pinned MIT-licensed OHCI transfer
walker, usb_hub.c and the device/control portion of usb_gamepad.c, generated
by scripts/generate-usb.py. Browser input replaces native XInput and host
threads; original source remains under upstream/tools/xboxrecomp/src/usb.
